# Nexus Intelligence: manual de marca

Manual de marca navegável (`index.html`), logos em SVG (`svg/`), tema de Power BI (`powerbi/`) e os scripts que geram tudo (`build/`).

Para regenerar os SVGs e o manual, edite os scripts em `build/` e rode `exportar_svgs.py` e `montar_brandbook.py`. Os SVGs não devem ser editados à mão.
